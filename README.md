# Order Management System

A complete, self-hosted PHP Order Management Platform with two-factor authentication, role-based access control, and a responsive modern UI.

---

## Features

- **Authentication** — Login with email + 2FA verification code, registration with email verification, password reset
- **Role-Based Access** — Three roles: `user`, `admin`, `super_admin` with granular permission enforcement
- **Order Management** — Create, view, edit, delete orders with status/priority tracking
- **Order History** — Full audit trail of every status change and update
- **Admin Panel** — Manage users (add, edit role, toggle active, reset password), manage all orders with bulk actions and CSV export
- **Email Notifications** — Verification codes, password resets, and welcome emails via SMTP with PHP mail() fallback
- **Installation Wizard** — Multi-step browser-based installer writes `config.php` and runs the database schema
- **No Dependencies** — Pure PHP 7.4+, MySQL, Vanilla JS. No Composer, no npm.

---

## Tech Stack

| Layer     | Technology                               |
|-----------|------------------------------------------|
| Backend   | PHP 7.4+ with PDO                        |
| Database  | MySQL 5.7+ / MariaDB 10.3+               |
| Frontend  | HTML5, CSS3 (custom properties), Vanilla JS |
| Email     | Custom SMTP client or PHP `mail()`       |
| Auth      | Session-based with DB token + 2FA codes  |
| Security  | CSRF tokens, bcrypt passwords, prepared statements |

## Quick Start

### 1. Upload Files
Upload all files to your web server's document root or a subdirectory.

### 2. Run the Installer
Navigate to `https://yourdomain.com/install.php` in your browser and follow the 5-step wizard.

### 3. Log In
Go to `https://yourdomain.com/auth/login.php` and sign in.

## File Structure

```
├── index.php              # Main dashboard
├── config.php             # (generated by installer)
├── config.example.php     # Configuration template
├── install.php            # Installation wizard
├── schema.sql             # Database schema
├── .htaccess              # Apache security rules
├── auth/                  # Login, register, verify, forgot/reset password
├── account/               # Profile settings, change password
├── admin/                 # Admin dashboard, user management, order management
├── orders/                # Order list, create, view, edit
├── includes/              # Shared PHP: db, auth, csrf, email, header, footer
├── assets/css/style.css   # Responsive stylesheet
├── assets/js/app.js       # Client-side interactions
└── docs/                  # Installation guide and user manual
```

---

## Post-Installation Security Checklist

1. Delete or restrict `install.php`
2. Set `config.php` permissions to `600` (`chmod 600 config.php`)
3. Set directory permissions to `755`, file permissions to `644`
4. Change the default admin password
5. Configure SMTP for email delivery
