# ProcessFlow Manager — Order Management System

A self-hosted standalone PHP platform converted from the **ProcessFlow Manager WordPress plugin**. Provides print-shop and production-workflow order management with QR code tracking, WhatsApp notifications, and a public customer tracking portal — no WordPress required.

---

## Features

### Workflow & Orders
- **Configurable Stages** — Define custom workflow stages (e.g. In Design → In Print Queue → In Finishing → Ready for Collection) with colors and WhatsApp message templates
- **Order Management** — Create, edit, view, archive, and delete orders with fields: customer name, business name, WhatsApp number, invoice number, job details, product lines
- **QR Code Tracking** — Each order gets a unique 128-bit QR hash; scan the QR with any device to view status and update stage
- **Stage History** — Full audit timeline of every stage change
- **Custom Fields** — Admin-defined extra fields that appear on all order forms
- **Archive/Unarchive** — Soft-delete orders to a Completed archive

### Notifications
- **WhatsApp Integration** — Per-stage message templates with `{customer_name}`, `{order_id}`, `{business_name}` placeholders; one tap opens WhatsApp web/app with pre-filled message

### Public Portal
- **Customer Tracking Portal** — Customers enter their order ID + last 4 digits of their WhatsApp number to view order status and progress bar (no login needed)
- **QR Scan Page** — Staff scan the QR code on the job ticket to view and update the order stage directly from their phone

### Administration
- **Admin Panel** — Manage users, stages, settings, custom fields
- **InvoiceNinja Integration** — Browse and import invoices from an InvoiceNinja instance as orders
- **Bulk Actions** — Archive, change stage, or delete multiple orders at once
- **CSV Export** — Export all orders as CSV
- **Backup & Restore** — Export/import a full JSON backup of all orders, stages, settings and custom fields
- **Settings** — Company details, WhatsApp defaults, InvoiceNinja API credentials, portal branding

### Authentication & Security
- **Email 2FA** — All logins require a 6-digit code sent to the user's email before access is granted
- **Role-Based Access** — Three roles: `user`, `admin`, `super_admin`
- **Secure Passwords** — bcrypt (cost 12), CSRF protection on all forms, PDO prepared statements throughout
- **Password Reset** — Secure tokenised email links with 1-hour expiry

## Tech Stack

| Layer     | Technology                               |
|-----------|------------------------------------------|
| Backend   | PHP 7.4+ with PDO                        |
| Database  | MySQL 5.7+ / MariaDB 10.3+               |
| Frontend  | HTML5, CSS3 (custom properties), Vanilla JS |
| Email     | Custom SMTP client or PHP `mail()`       |
| QR Codes  | Google Charts API (server-side generation) |
| Auth      | Session-based with DB token + email 2FA  |
| Security  | CSRF tokens, bcrypt passwords, prepared statements |

## Quick Start

### 1. Upload Files
Upload all files to your web server's document root or a subdirectory.

### 2. Run the Installer
Navigate to `https://yourdomain.com/install.php` in your browser and follow the 5-step wizard.

### 3. Log In
Go to `https://yourdomain.com/auth/login.php` and sign in.

## File Structure

```
├── index.php              # Dashboard (stage-based stats + recent orders)
├── config.php             # (generated by installer)
├── config.example.php     # Configuration template
├── install.php            # Installation wizard
├── schema.sql             # Database schema
├── .htaccess              # Apache security rules
├── auth/                  # Login, register, verify, forgot/reset password

├── admin/
│   ├── dashboard.php      # Admin overview with stage stats
│   ├── users.php          # User management
│   ├── orders.php         # All orders with bulk actions, CSV export, import

│   └── settings.php       # System settings, custom fields, backup/restore
├── orders/
│   ├── index.php          # Order list (filter by stage, search)
│   ├── create.php         # New order form
│   ├── view.php           # Order detail with QR code and WhatsApp button
│   ├── edit.php           # Edit order
│   ├── qr.php             # QR scan page — no login required (for staff)
│   └── track.php          # Customer tracking portal — no login required

├── assets/css/style.css   # Responsive stylesheet
├── assets/js/app.js       # Client-side interactions
└── docs/                  # Installation guide and user manual
```

## Post-Installation Security Checklist

1. Delete or restrict `install.php`
2. Set `config.php` permissions to `600` (`chmod 600 config.php`)
3. Set directory permissions to `755`, file permissions to `644`
4. Change the default admin password
5. Configure SMTP for email delivery
6. Configure WhatsApp default country code in **Settings → WhatsApp**
